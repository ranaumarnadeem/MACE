# MACE documentation

MACE documentation is published on GitHub Pages at
https://ranaumarnadeem.github.io/MACE/. It is a Sphinx site with the Read the
Docs theme, laid out like the CVA6 documentation, and can be generated by
running `make` in this directory:

```bash
pip install -r requirements.txt
make
```

The site is written to `_build/`; open `_build/index.html`. A push to `main`
that touches `docs/` rebuilds and redeploys it
(`.github/workflows/docs.yml`); pull requests only build it.

Each part lives in its own numbered directory with an `index.rst` toctree:

| Directory | Part |
|---|---|
| `01_mace_user/` | MACE User Manual |
| `02_mace_requirements/` | MACE Requirements Specification |
| `03_mace_design/` | MACE Design Document |
| `04_chia_openpiton/` | chia_openpiton Adapter |
| `05_mace_cores/` | Supported Cores |
| `06_mace_evaluation/` | MACE Evaluation |

Pages are reStructuredText; Markdown (`.md`) also works through
`myst_parser`. The standalone notes already in this directory
(`TECHNICAL_GUIDE.md` and the GCP write-ups) are excluded from the site in
`conf.py`.
